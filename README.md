# JavaScript Learning Journey 🚀

A collection of JavaScript practice exercises covering fundamentals to intermediate concepts — from variables and functions to a working **Student Grade Tracker** mini-project.

## 📚 Topics Covered

- **Variables & Data Types** — `let`, `const`, `typeof`, operators
- **Functions** — Declarations, expressions, arrow functions, default parameters
- **Control Flow** — If/else, switch, loops (`for`, `while`, `for...of`)
- **Arrays** — `map`, `filter`, `reduce`, `find`, `sort`, `some`, `every`
- **Objects** — Properties, methods, nesting, iteration
- **Arrays of Objects** — Real-world data handling
